# 九个 Canvas CLI 技能职责收敛

## Why
用户明确要求保留九个 `dreamina-canvas-cli*` 入口，并将重复辅助技能降为标准操作文档。当前认证、安装、节点模式和通用提交恢复在多套技能中重复维护，容易产生路由和参数漂移。

## What Changes
- 保留总入口、setup、auth、text2image、image2image、text2video、ref2video、text2voice、text2audio 九个 CLI 技能。
- 将模型发现、画布、资源、报价执行、恢复、文本元素和时间轴合并至总技能的按需参考与示例。
- 将模式约束归入对应生成技能；认证及安装细节归入对应入口。
- 保留编排、评估和历史 CLI；历史 CLI 只响应明确的旧版请求。
- 移除 12 个重复 Canvas 技能和 dreamina-setup 的可安装目录，迁移全部独有内容，提供迁移映射；旧名字由文档说明替代，不继续自动触发。
- **BREAKING**：消费者固定引用的辅助技能路径需要按迁移映射更新。用户指定的九个入口保持不变。

## Impact
涉及技能目录、清单、文档、命令归属、场景与测试。发布/消费插件更新不在本次本地实施范围。保留未提交工作备份，不创建或切换分支，不提交、不付费生成。
