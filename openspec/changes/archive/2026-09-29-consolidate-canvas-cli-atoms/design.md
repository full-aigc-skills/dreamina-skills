# 设计

一个操作只有一个规范维护位置；场景示例组合操作，不新增同义技能。九个 CLI 技能显式调用，canvas-use 为隐式编排入口。design-use 仅做产品级路由，不引用私有 Python 实现。

每个操作记录输入/前置条件、动作/副作用、输出、恢复和验收。公共规则由总技能维护；模式差异由六个生成技能维护。跨技能按名称与安装指引交接，技能内相对链接必须独立可解析。

迁移前备份所有当前工作区文件。保留原始场景中的领域细节；删除重复通用质量模板。对历史 canary 单独标记旧证据，当前重构不继承已验收声明。

验证：目录/manifest 一致、命令归属可解析、独立安装资源校验、旧路径无活动引用、模式约束回归、实时 schema 只读核对、TRACE、OpenSpec strict。静态通过不代表真实生成验收。
