# dreamina-canvas-compose 错误与恢复

| 情况 | 安全判断 | 动作 |
|---|---|---|
| 预检失败 | 尚未产生副作用 | 修正输入后重新预检 |
| 调用前拒绝 | 尚未执行 | 返回缺失条件，不自动降级到危险路径 |
| 超时/连接中断 | 结果可能已提交 | 使用请求 ID 查询状态，禁止盲目重提 |
| 部分成功 | 已产生部分产物 | 保存回执，仅补做可证明未完成的步骤 |
| 验证失败 | 产物存在但不合格 | 隔离产物，给出修复方案，等待确认 |
| 权限或预算不足 | 无权继续 | 停止并报告所需权限/预算，不替用户扩大授权 |

恢复报告必须包含：原请求标识、最后确认状态、已复用内容、新执行内容、未完成项和下一人工决策点。
