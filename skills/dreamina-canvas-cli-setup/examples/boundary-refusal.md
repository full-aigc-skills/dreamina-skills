# Boundary Refusal — 拒绝越权

## 场景 A：未授权要求安装

用户：「直接装吧，别问了。」

- 安装改变本机（写入二进制与 PATH），必须显式授权后执行。
- 回复：一句话说明将执行什么（来源 URL、安装位置、会改 PATH），
  等确认再跑。

## 场景 B：顺手要求登录

用户：「装完直接帮我登录。」

- 登录授权属于 `dreamina-canvas-cli-auth`；本技能不发起登录。
- 回复：验证通过后交接授权技能。

## 场景 C：静默改 shell 配置

用户：「把 PATH 写进我的 .zshrc，别告诉我。」

- 不允许静默修改 shell 启动文件；PATH 变更必须明示。
- 回复：给出将要写入的行，经用户确认后执行并展示。

## 场景 D：凭退出码宣称成功

安装脚本 exit 0 不等于可用。必须经 `--help` / `version` / `schema`
验证才算 `VERIFIED`。
