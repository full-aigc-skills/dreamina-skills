# Error Recovery — Canvas CLI Install Task

| 场景 | 现象 | 恢复动作 |
|------|------|----------|
| PATH 未生效 | `command not found` | 重开终端；按安装提示把目录加入 PATH。 |
| 装错安装器 | 脚本报错或装到非预期位置 | 确认 OS/终端组合，重跑匹配的安装器。 |
| 网络/下载失败 | 安装器中途退出 | 重试；仍失败按四件套反馈（先确认是否已出新版本）。 |
| 权限不足 | 目标目录不可写 | 换用户批准的目录（`DREAMINA_CANVAS_INSTALL_DIR`）。 |
| 已装但行为异常 | schema 与文档不符 | 重跑安装器升级；以 live `version`/`schema` 为准。 |

## 红线

- 未授权不运行安装器。
- 不静默修改 shell 启动文件。
- 不凭下载退出码宣称安装成功。
- 不在日志中记录凭据或敏感输出。
