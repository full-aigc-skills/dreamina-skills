# 样片、批量生成与返修操作契约

| 维度 | 约束 |
|---|---|
| 输入 | 用户目标、已有创作上下文、文件路径、画布或节点身份 |
| 查询 | 用 `jimeng-novel <命令> --help` 和 `schema get --command` 核对现行参数 |
| 写入 | 保存草稿与提交生成分别记录；只修改当前阶段授权范围 |
| 计费 | 不确定价格说明未知；`node run`、剧本服务与转写按相应费用规则取得批准 |
| 恢复 | 等待超时、网络中断或状态不明时保存身份，只查询原任务 |
| 交付 | 报告路径、状态、实际费用、已检查内容和未验证内容 |

CLI 1.0.1 的本机帮助是此表的核对基线。用户资料和凭据不写进技能包或测试夹具。
